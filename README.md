# Teja Swaroop Korupolu Portfolio

React portfolio site for Teja Swaroop Korupolu, built with Vite and Three.js.

## Run locally

Install dependencies and run the Vite development server:

```bash
npm install
npm run dev
```

Create and preview a production build:

```bash
npm run build
npm run preview
```

The hero uses a pointer-responsive Three.js scene, with reduced-motion and WebGL-unavailable fallbacks. Project, experience, contribution, and toolkit content is organized into reusable React components/data.
